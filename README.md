# JobNet VIP - כלים לקריירה וחישובי שכר בישראל

אתר כלים חינמי לעובדים ולמחפשי עבודה בישראל, המשלב סריקת קורות חיים לפני שליחה למעסיקים לצד מחשבוני שכר וזכויות עובדים המעודכנים לשנת 2026.

**כתובת האתר:** [https://jobnet.vip](https://jobnet.vip)

### מה תמצאו באתר:
- **בדיקת קורות חיים לפני שליחה:** זיהוי התאמה למערכות סינון אוטומטיות והתראות על פורמט הקובץ (Word מול PDF), בסריקה מקומית בדפדפן וללא שמירת קבצים בשרת.
- **מחשבון שכר ברוטו לנטו:** חישוב שכר נטו לפי מדרגות מס הכנסה, נקודות זיכוי, ביטוח לאומי, פנסיה, קרן השתלמות, שווי רכב צמוד ועלות מעסיק.
- **מחשבונים ייעודיים:** [מחשבון שכר הייטק](https://jobnet.vip/tech-salary.html), [מחשבון אופציות ו-RSU](https://jobnet.vip/options-rsu.html), [מחשבון פיצויי פיטורים](https://jobnet.vip/severance-pay.html) ו[מחשבון שכר מינימום](https://jobnet.vip/minimum-wage.html).
